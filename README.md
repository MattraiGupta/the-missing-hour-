# The Missing Hour
### Act One

A noir mystery visual novel built with Python and Pygame.

---

## Story

**Case File No. 17-4.**  
Rayan Malik. Twenty-four. Missing after a rooftop birthday party at The Gilt Room.  
Last seen between 11 PM and midnight. No signs of struggle. No witnesses.  
Five people were there. Every single one says the same thing:

> *"I don't remember."*

---

## Requirements

- Python 3.8+
- Pygame

```bash
pip install pygame
```

---

## Running the Game

```bash
python main.py
```

---

## Assets Required

Place the following image files in the same directory as `main.py`:

| File | Description |
|------|-------------|
| `logo.png` | Title screen logo (480×480) |
| `env.png` | Envelope (900×375) |
| `letter.png` | Case letter (480×570) |
| `office.png` | Office background (1280×720) |
| `dialogue_box.png` | Dialogue UI overlay (1280×200) |
| `diya_neutral.png` | Diya — neutral expression |
| `diya_tired.png` | Diya — tired expression |
| `diya_sad.png` | Diya — sad expression |
| `diya_smug.png` | Diya — smug expression |
| `diya_smiling.png` | Diya — smiling expression |
| `diya_soft.png` | Diya — soft expression |
| `diya_angry.png` | Diya — angry expression |
| `diya_surprised.png` | Diya — surprised expression |

> All character sprites are auto-scaled to a max height of 320px.

---

## Controls

- **Click** — advance dialogue / interact
- **ESC** — exit prompt
- **SKIP >>** — skip to case file
